-- Section 14: The AIMS class must be updated to handle any exception generated when the play() method is called. What happens when you don't update them for the catch?

If you do not update the Aims class to catch the exception thrown by play(), the program may terminate unexpectedly when an invalid media is played, 
causing: a stack trace to be printed, the current program flow to stop or possibly terminating the application.
So the purpose of updating Aims is to gracefully handle playback errors instead of crashing the program.
