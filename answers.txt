-- Section 12: 
1)if we use this approach, The Media class should implement the Comparable<Media> interface because all media types (Book, CompactDisc, DigitalVideoDisc) inherit from it. This allows media objects to be compared and sorted directly.

2)The compareTo() method should implement a default ordering rule. For example, for sorting by title then cost:
@Override
public int compareTo(Media other) {
    int titleCompare = this.getTitle().compareTo(other.getTitle());

    if (titleCompare == 0) {
        return Float.compare(other.getCost(), this.getCost());
    }

    return titleCompare;
}

3) We cannot have 2 ordering rules, using the Comparable interface only allows one natural ordering because a class can only have one compareTo() implementation

4)If DVDs require a different ordering rule, using only Comparable becomes difficult because different media types would require different comparison logic. In this case, using separate Comparator classes is a better design because each media type or ordering rule can have its own comparator implementation without affecting the others.
